HTML Basics

HTML stands for Hypertext Markup Language. It defines the structure of your web page using various elements like headings, paragraphs, and links.

Example:

<h1>Welcome to My Website</h1>
<p>This is a paragraph of text on my page.</p>
<a href="https://www.example.com">Click here</a> to visit my site.

This HTML code creates a heading, a paragraph, and a clickable link.

CSS Basics

CSS (Cascading Style Sheets) is used to control the look and feel of the HTML elements. You can change colors, fonts, layouts, and more.

Example:

body {
  background-color: #f4f4f9;
  font-family: Arial, sans-serif;
}

h1 {
  color: #4CAF50;
  text-align: center;
}

This CSS code sets the background color of the page and changes the font and color of the <h1> element.

JavaScript Basics

JavaScript is a programming language used to make your website interactive. With it, you can create things like buttons that do something when clicked.

Example:

<button onclick="alert('Hello, world!')">Click Me</button>

This button, when clicked, will show a pop-up with the message "Hello, world!"

Exercise:

Modify the above code to show a custom message in the alert box. You can change the text inside the alert() function.

Advanced HTML Elements

Let's explore some advanced HTML elements:

Forms

Forms allow users to enter data.

Example:

<form>
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <input type="submit" value="Submit">
</form>

Tables

Tables are useful for displaying data in rows and columns.

Example:

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
</table>

Intermediate JavaScript

JavaScript allows us to create dynamic content by using variables, functions, and more.

Example:

let age = 10;
function greet() {
  alert('Hello! You are ' + age + ' years old.');
}

greet();

This JavaScript code uses a variable age and a function greet() to show a personalized message when called.
